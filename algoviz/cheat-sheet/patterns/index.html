Remember earlier work so each lookup replaces another scan.

Know this
Use Set for membership and Map for counts or indices. Decide exactly what each key represents.
Keep true
Before processing index i, the map contains only earlier indices.
Watch for
Look up the complement before inserting the current value, or you can reuse the same index. Check undefined, not truthiness: index 0 is valid.

Time O(n) expected Space O(n)

Trace ittwoSum([2, 7, 11, 15], 9) → [0, 1]

↑ Contents Next → Two pointers

Move the pointer whose current position you can safely rule out.

Know this
For a sorted pair sum: too small → move left forward; too large → move right backward. Be able to explain why the discarded candidates cannot work.
Keep true
If a valid pair remains, both of its indices are inside [left, right].
Watch for
The movement rule depends on the problem. Sorting costs O(n log n) and loses original indices unless you preserve them.

Time O(n) on sorted input Space O(1)

Trace itsortedPair([1, 3, 4, 6], 7) → [0, 3]

See it move Container With Most Water ↗Trapping Rain Water ↗

Extend the right edge; shrink the left edge until the window is valid.

Know this
Track just enough to add and remove an item. For longest valid windows, record after repair; for shortest covering windows, record while shrinking a valid window.
Keep true
After the while loop, this example’s window contains no repeated character.
Watch for
Contiguous is not a subsequence. Negative values break the usual sum-based shrinking rule; exact sums with negatives often need prefix sums + a map.

Time O(n) expected Space O(n)

Trace itlongestUnique("abcabcbb") → 3

← Previous Two pointers ↑ Contents Next → Prefix sums

A range sum is the difference between two prefix sums.

Know this
Build prefix[0] = 0 and prefix[i + 1] = prefix[i] + a[i]. Then sum of [l, r) is prefix[r] − prefix[l]. For target k, count previous prefixes equal to sum − k.
Keep true
The frequency map counts prefixes ending before the current prefix.
Watch for
Seed frequency 0 with 1 to count ranges starting at index 0. Look up before incrementing, especially when k = 0.

Time O(n) expected Space O(n)

Trace itcountSum([1, -1, 0], 0) → 3

See it move Range Sum Query ↗Subarray Sum Equals K ↗

← Previous Sliding window ↑ Contents Next → Binary search

Keep the answer boundary and discard half the search space each time.

Know this
Learn one boundary template: first index with a[i] ≥ target. For “minimum capacity/time that works,” replace the comparison with a monotone feasibility test.
Keep true
Indices before lo are too small; indices at or after hi meet the target. The boundary stays in [lo, hi].
Watch for
The result can be a.length. Exact search needs an equality check afterward. Prove monotonicity before searching an answer space.

Time O(log n) Space O(1)

Trace itlowerBound([1, 3, 3, 7], 3) → 1

See it move Search Rotated Array ↗Time Based Key-Value Store ↗

← Previous Prefix sums ↑ Contents Next → Sorting & intervals

Sort endpoints so only the current merged interval needs attention.

Know this
Merge by start time. Select the most non-overlapping intervals by end time. Count simultaneous events with a sweep or a min-heap of end times.
Keep true
The output stays sorted and disjoint; only its last interval can overlap the next input.
Watch for
Agree on closed [a, b] versus half-open [a, b) endpoints. Touching closed intervals merge; half-open meetings can reuse a room at the same time.

Time O(n log n) Space O(n)

Trace itmergeIntervals([[1, 3], [2, 6], [8, 10]]) → [[1, 6], [8, 10]]

See it move Merge Intervals ↗Meeting Rooms II ↗Skyline Sweep ↗

← Previous Binary search ↑ Contents Next → Stacks

The last unfinished item is the first one you resolve.

Know this
Use an array with push/pop. For matching brackets, push openings and compare each closing bracket with the top.
Keep true
The stack contains exactly the openings that still need a matching close.
Watch for
A closing bracket can arrive with an empty stack. A nonempty stack at the end is also invalid.

Time O(n) Space O(n)

Trace itvalidBrackets("([])") → true

See it move Valid Parentheses ↗Exclusive Time of Functions ↗

← Previous Sorting & intervals ↑ Contents Next → Monotonic stacks & deques

Keep unresolved candidates in order; remove candidates the new item beats.

Know this
Store indices. A stack resolves next-greater queries; a deque keeps window candidates, discarding expired indices from its front and dominated values from its back.
Keep true
This stack holds unresolved indices in non-increasing value order.
Watch for
Choose < versus ≤ based on whether equal values count. Each index enters and leaves once, so the nested while loop is still linear.

Time O(n) Space O(n)

Trace itnextGreater([2, 1, 2, 4, 3]) → [4, 2, 4, -1, -1]

See it move Sliding Window Maximum ↗

← Previous Stacks ↑ Contents Next → Linked lists

Keep references to the nodes you will need before changing any link.

Know this
Reversal needs prev/current/next. Fast/slow pointers find a middle or cycle in O(n) time and O(1) space. A dummy node simplifies deleting or inserting at the head.
Keep true
prev heads the reversed prefix; current heads the untouched suffix.
Watch for
Save current.next before overwriting it. Compare node identity for cycles, not node values. This reversal assumes an acyclic list.

Time O(n) Space O(1)

Trace it1 → 2 → 3 becomes 3 → 2 → 1

See it move Reverse Linked List ↗Linked List Cycle ↗

← Previous Monotonic stacks & deques ↑ Contents Next → Trees & recursive DFS

Define what one subtree returns, then combine its children’s answers.

Know this
Write the null case first. Preorder acts before children; inorder visits left/node/right; postorder combines child results. BST validation passes ancestor bounds down.
Keep true
Each call returns the correct result for the entire subtree rooted at its argument.
Watch for
Tree height can be n, so recursion can overflow the JS call stack. A graph needs a visited set; a proper tree does not.

Time O(n) Space O(h) call stack

Trace itmaxDepth(null) → 0; a three-node chain → 3

See it move Validate BST ↗Lowest Common Ancestor ↗

← Previous Linked lists ↑ Contents Next → Breadth-first search

Visit everything one step away before anything two steps away.

Know this
Use a FIFO queue and mark visited when enqueuing. For level-by-level work, freeze the queue’s end index before processing a level.
Keep true
Vertices leave the queue in nondecreasing distance; first discovery gives the shortest unweighted distance.
Watch for
BFS does not solve general weighted shortest paths. Avoid repeated Array.shift(); use a head index.

Time O(V + E) Space O(V) auxiliary

Trace itdistances([[1, 2], [3], [3], []], 0) → [0, 1, 1, 2]

See it move Level Order Traversal ↗Number of Islands ↗

← Previous Trees & recursive DFS ↑ Contents Next → Graphs & flood fill

Explore one connected region, marking nodes so cycles cannot repeat work.

Know this
Represent edges with adjacency lists. For a grid, neighbors are adjacent cells. To count components, launch a traversal from every still-unvisited node.
Keep true
Each discovered vertex is marked before it can be added to the stack again.
Watch for
A single start misses disconnected components. Directed-cycle detection needs active/finished states, not just a single visited flag.

Time O(V + E) Space O(V) auxiliary

Trace itcomponents([[1], [0], []]) → 2

See it move Number of Islands ↗Clone Graph ↗

← Previous Breadth-first search ↑ Contents Next → Topological sort

Repeatedly take a node with no remaining prerequisites.

Know this
For edge u → v, increment indegree[v]. Queue all zero-indegree nodes, emit each one, and decrement its outgoing neighbors. Fewer than V emitted means a cycle.
Keep true
A queued vertex has no incoming edges from any unprocessed vertex.
Watch for
Use the correct edge direction. Include isolated nodes. If you deduplicate adjacency edges, deduplicate their indegree increments too.

Time O(V + E) Space O(V) auxiliary

Trace ittopo([[1], [2], []]) → [0, 1, 2]

See it move Course Schedule ↗Alien Dictionary ↗

← Previous Graphs & flood fill ↑ Contents Next → Union-find

Give each component a representative and merge representatives.

Know this
find follows parent links; union connects roots. Path compression plus union by size makes operations almost constant amortized time.
Keep true
Two items are connected exactly when find returns the same root.
Watch for
Merge roots, not arbitrary nodes. Union-find does not give paths and does not efficiently handle arbitrary edge deletions.

Time O(α(n)) amortized per operation Space O(n)

Trace itunion(0, 1); union(1, 2); find(0) === find(2)

See it move Accounts Merge ↗

Share the common prefixes of words in a tree of characters.

Know this
Each node maps a character to a child. A terminal flag distinguishes a complete word from a prefix. Traversing L characters takes O(L) expected time.
Keep true
The path from the root spells the prefix represented by the current node.
Watch for
A found path is not necessarily a full word. Autocomplete also costs time proportional to the results you traverse and return.

Time O(L) expected per insert/lookup Space O(total inserted characters)

← Previous Union-find ↑ Contents Next → Heaps & priority queues

Keep the next highest-priority item at the root without sorting everything.

Know this
A binary heap has O(1) peek and O(log n) push/pop. For kth largest, keep a min-heap of size k: its root is the smallest retained winner.
Keep true
After each item, the heap holds the largest min(k, items seen) values.
Watch for
A heap’s array is not fully sorted. Define the comparator direction and tie-breaks. Confirm whether the interview environment supplies a priority queue.

Time O(n log(k + 1)) Space O(k)

Trace itkthLargest([3, 2, 1, 5, 6, 4], 2) → 5

See it move Kth Largest ↗Merge k Sorted Lists ↗Median from Data Stream ↗

← Previous Tries ↑ Contents Next → Backtracking

Choose, explore, undo; abandon a branch as soon as it cannot work.

Know this
Define the partial answer, available choices, and stopping rule. Use a start index for combinations and a used set/array for permutations. Copy each completed answer.
Keep true
On returning from a recursive call, the shared path is restored to its previous contents.
Watch for
Pushing path itself aliases every answer. Duplicate inputs need a deliberate skip rule. Exponential output means exponential work is unavoidable.

Time O(n · 2ⁿ) for all subsets Space O(n) auxiliary; O(n · 2ⁿ) output

Trace itsubsets([1, 2]) → [[], [1], [1, 2], [2]]

See it move Generate Parentheses ↗

← Previous Heaps & priority queues ↑ Contents Next → Dynamic programming

Name each subproblem precisely and compute its answer once.

Know this
Write state → transition → base cases → evaluation order → final answer. Memoize all state dimensions, or fill a table in dependency order. Time = states × work per state.
Keep true
When dp[sum] is computed, every smaller amount it depends on already has its best answer.
Watch for
Greedy coin choice can fail: [1, 3, 4], amount 6 needs 3 + 3. Zero often means a valid answer, so use Infinity for unreachable minimum-cost states.

Time O(amount · coins.length) Space O(amount)

Trace itcoinChange([1, 3, 4], 6) → 2

See it move Climbing Stairs ↗Coin Change ↗Edit Distance ↗

← Previous Backtracking ↑ Contents Next → Greedy algorithms

Make a choice you can show never makes the remaining solution worse.

Know this
Explain an exchange argument: an optimal solution can replace its first choice with yours without losing quality. For non-overlapping meetings, choose the earliest finish.
Keep true
After choosing each meeting, the selected set leaves as much remaining time as possible among equally large feasible selections.
Watch for
“Seems best now” is not a proof. Earliest start and shortest duration are not valid substitutes for earliest finish in interval scheduling.

Time O(n log n) Space O(n) for the sorted copy

Trace itmaxMeetings([[1, 3], [2, 4], [3, 5]]) → 2

See it move Non-overlapping Intervals ↗Task Scheduler ↗

← Previous Dynamic programming ↑ Contents Next → Weighted shortest paths

Dijkstra expands the unsettled vertex with the smallest known distance.

Know this
Relax each edge: if distance[u] + weight improves distance[v], save it and enqueue it. Use BFS for equal weights; Dijkstra requires nonnegative weights.
Keep true
A non-stale minimum-distance entry popped from the heap has its final shortest distance.
Watch for
Skip stale heap entries after an improvement. Negative edges require another algorithm, such as Bellman–Ford; unreachable vertices stay Infinity.

Time O(V + E log(E + 1)) with lazy heap entries Space O(V + E) auxiliary

Trace itdijkstra([[[1, 4], [2, 1]], [], [[1, 2]]], 0) → [0, 3, 1]

← Previous Greedy algorithms ↑ Contents Next → Divide & conquer

Solve smaller versions, then combine their answers.

Know this
Merge sort splits in half and merges sorted halves. Its log n levels each do O(n) work. Know quicksort’s expected O(n log n), worst O(n²), and quickselect’s expected O(n).
Keep true
Before merging, both halves are sorted; the output prefix contains the smallest items consumed so far.
Watch for
Account for the combine work and allocation. This allocating merge sort uses O(n) peak auxiliary space; it is not in-place.

Time O(n log n) Space O(n) peak auxiliary

Trace itmergeSort([4, 1, 3, 2]) → [1, 2, 3, 4]

← Previous Weighted shortest paths ↑ Contents Next → Bits & basic math

Use an algebraic property that removes unnecessary enumeration.

Know this
x ^ x = 0 and x ^ 0 = x; n & (n − 1) clears the lowest set bit. For greatest common divisor, repeatedly replace (a, b) with (b, a % b).
Keep true
The XOR accumulator equals the XOR of all values processed; equal pairs cancel.
Watch for
Number bitwise operators coerce to 32-bit integers. Use BigInt for wider integer bit operations, and never mix bigint and number operands.

Time O(n) for singleNumber Space O(1)

Trace itsingleNumber([4, 1, 2, 1, 2]) → 4

Language check

TypeScript details worth remembering

Numbers need a comparator

[...a].sort((x, y) => x - y)

Default sort compares strings; sort mutates its array. Copy if the input must stay unchanged.

Use a queue head

const item = queue[head++];

Keep push for enqueue. Repeated shift can move every remaining element. A head index retains consumed slots, so this queue uses O(total enqueued) storage.

Zero is a value

count.set(x, (count.get(x) ?? 0) + 1);

Check map.has(key) or value !== undefined. A stored index or count of 0 is not missing. Map and Set compare objects by identity.

Each matrix row needs its own array

Array.from({length: rows}, () => Array<number>(cols).fill(0))

Using fill with a single inner array makes every row share the same object.

Know your integer range

Number.MAX_SAFE_INTEGER // 2 ** 53 - 1

Use bigint if exact integer results can exceed this range. Number bitwise operations use 32-bit values. BigInt arithmetic has a cost that grows with its bit length.

Be precise about strings and !

const characters = [...text];

This iterates Unicode code points; text[i] uses UTF-16 code units. Neither handles every visible grapheme. In templates, ! asserts an index already proved valid; it adds no runtime check.

Complexity shorthand assumes constant-cost numeric operations and expected O(1) hash lookups. Include sorting, copied arrays, the recursion stack, and returned output when explaining your costs.

Keep one implementation handy

Reusable binary heap

Pass (a, b) => a < b for a min-heap or (a, b) => a > b for a max-heap. Array indices: parent ⌊(i − 1) / 2⌋, children 2i + 1 and 2i + 2. The heap and shortest-path templates use it; their Copy buttons include it.
